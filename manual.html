隨手記帳 — 手動記帳 ＋ 電子發票 QR Code 掃描記帳

← 回到 App
⚠ 這是一個離線優先的個人記帳工具，所有資料預設只存在你自己的手機瀏覽器裡。 備份功能是選用的，用「匯出/匯入 JSON 檔」自己保管，不連任何雲端服務，詳見本頁「備份/還原」一節。

這是什麼工具？

一個安裝在手機主畫面上使用的漸進式網頁應用（PWA），用來記帳。除了手動輸入之外，也可以用手機相機掃描台灣電子發票上的 QR Code，自動把金額、日期、發票號碼等資訊帶入記帳表單。

App 完全離線可用（新增/編輯/查詢/報表/備份匯出匯入都不需要網路），只有相機掃描需要 https 安全連線（不一定要連上網路本身）。

安裝到手機主畫面

App 網址：https://m255525.github.io/expense-tracker-pwa/

  1. 用手機的 Chrome 瀏覽器開啟上面的網址。
  2. 點瀏覽器選單裡的「加入主畫面」，或 App 內「設定」頁籤的「加入主畫面」按鈕。
  3. 之後就會像一般 App 一樣有獨立圖示，開啟時不會看到瀏覽器網址列。
💡 這個網址的原始碼放在公開的 GitHub repo，任何人都看得到程式碼，但看不到你的記帳資料——資料只存在你自己的手機（IndexedDB），不會傳到任何伺服器。

手動記帳

  1. 底部點「新增」。
  2. 選「支出」或「收入」。
  3. 輸入金額、日期，選一個分類（emoji 卡片）。
  4. 商家/項目、備註可填可不填。
  5. 點「儲存」。

掃描電子發票記帳

  1. 底部點「新增」，再點「📷 掃描電子發票 QR Code」。
  2. 把發票左側的 QR Code 對準框內，稍等自動辨識。
  3. 辨識成功後，金額、日期、發票號碼、賣方統編（若有品項也會一併帶入）會自動填入表單。
  4. 確認/補上分類，需要的話調整商家名稱，點「儲存」。
💡 掃到的 QR Code 如果不是電子發票格式，會提示「無法辨識」並導向手動輸入，不會當機或卡住。
💡 同一張發票重複掃描存檔前會提醒「這張發票已經記過帳了」，但仍可選擇繼續存（例如部分退款的情況）。

列表與搜尋

底部「列表」可依收支類型、分類篩選，也可以搜尋商家/備註關鍵字。紀錄依日期分組，點任一筆可以編輯或刪除。

分類管理

「設定」頁籤裡的「管理分類」可以新增大分類（例如「餐飲」）、在每個大分類底下新增子分類（例如「早餐」「午餐」）、調整排序、把子分類移到別的大分類底下、編輯名稱與圖示，以及封存不再使用的分類。封存大分類會連同底下的子分類一起封存；封存的分類不會出現在新增紀錄的選單裡，但歷史紀錄仍會正確顯示原本的分類。

記帳時可以只選大分類，也可以再往下選更精確的子分類（有子分類的大分類才會出現子分類選項）；分類篩選與報表統計都會自動把子分類的紀錄算進所屬的大分類裡。新增分類時可以直接點「選圖示」從常見 emoji 中挑選，不用自己打字輸入 emoji。

報表

底部「報表」選擇月份後，會看到當月收入/支出/淨額、支出分類佔比圖、每日收支趨勢圖。圖表下方都有「顯示表格」可以看原始數字。

備份 / 還原

資料預設只存在這台裝置。到「設定」頁籤點「匯出備份」，會下載一個 JSON 檔案——你可以自己把它存到 Google Drive、Dropbox 等你原本就在用的雲端硬碟資料夾，或傳給自己保存，當作雲端備份。

換新手機時，把備份檔傳到新手機上，到「設定」頁籤點「匯入備份」選那個檔案即可。匯入是「合併」不是「覆蓋」——同一筆紀錄以較新的為準，不會不小心蓋掉其他資料，重複匯入同一份備份也不會出問題。

這不需要任何帳號、後端或連網設定，純粹是檔案的匯出/匯入。

常見問題

相機打不開 / 沒有掃描畫面？

檢查網址是否為 https:// 開頭（或 localhost），並確認瀏覽器已授權相機權限。

掃描一直辨識不出來？

確認對準的是發票左側的 QR Code（不是右側的品項明細碼），並盡量保持對焦、光線充足。

資料會不會外流？

所有資料只存在你自己的手機瀏覽器裡，這個 App 不會把資料傳到任何伺服器。備份檔要存去哪裡（雲端硬碟、傳給自己等）完全由你自己決定與管理。
